# C - malloc, free

This directory contains C programs that use dynamic memory allocation
with malloc and free.

## Files

| File | Description |
|------|-------------|
| 0-create_array.c | Function create_array that creates an array of chars and initializes it with a specific char. |
| main.h | Header file with the function prototypes. |
